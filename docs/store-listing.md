## English (en-US)

**Product name:** Edukors Text Editor

**Short description:** A Word-like text editor for teachers, with an AI assistant at your side. Free and open source.

**Description:**

Edukors Text Editor is a free word processor made for teachers and writers. Documents are laid out like Word's, on an
A4 page with 20 mm margins, with marks where each PDF page ends.

Write with headings, lists, quotes, links, fonts, colors and alignment, and Markdown shortcuts while you type. Insert
tables, shapes and pictures. Find and replace keeps the formatting. Open DOCX, Markdown, text and PDF files; export
PDF, text and Markdown; print with the same page as the PDF.

An optional AI assistant writes, rewrites and formats the document on request, and you approve each change. It runs
on Claude Code or Codex, installed on your computer, with your own AI account.

Part of Edukors.org, a project of open tools for teaching and learning, together with the Slides Editor and the Graph
Editor. MIT license.

**Features:**
- A4 page with PDF page marks
- Headings, lists, quotes, links, fonts, colors and alignment
- Tables, shapes and pictures
- Find and replace that keeps formatting
- Open DOCX, Markdown, text and PDF
- Export PDF, text and Markdown, and print
- Optional AI assistant that asks before each change
- English, Portuguese and Spanish

**Keywords:** text editor, word processor, teachers, education, AI, Markdown, DOCX
